> **작성 안내**
> - `(작성)` : 채워야 할 값이나 설명
> - `[미정]` : 아직 고르지 않은 결정
> - `[확인]` : 답을 반영했지만, 확인하거나 추가로 정해야 하는 부분
> - `(기본안)` : 제안해 둔 기본 규칙. 그대로 써도 되고 고쳐도 된다. 확정하면 표시를 지운다.
> - 위 표시는 모두 문서 끝 「남은 작업」에 모아 두었다. 수치는 초기값만 정하고 플레이하며 조정한다.

## 1. 플레이어 조작
- 1인칭, 화면 중앙 조준선
- WASD로 이동하고, 마우스로 시점을 돌린다. 달리기, 점프는 없다. (기본안)
- 플레이어는 조준선을 이용해 일정 거리 내에 있는 조작 오브젝트(버튼, 슬라이더 등)를 조작할 수 있다.
- 매뉴얼 열람 : 후면 벽의 매뉴얼은 다가가서 그대로 읽을 수 있고, 클릭하면 화면에 확대해서 볼 수도 있다.
	- 확대 중에는 이동과 시점 회전을 멈추고, 다시 클릭하면 닫는다. (기본안)
	- 확대해서 보는 동안에도 진행도와 타이머는 멈추지 않는다. (기본안)

## 2. 공간 구조
- 플레이어는 육면체의 한정된 공간 안에 갇혀 있다.
- 육면체 공간은 전면, 후면, 좌측면, 우측면으로 구분한다.
- 전면에는 현재 게임 상태를 표시하는 메인 패널이 있다.
- 좌, 우측면에는 설비의 조작 오브젝트가 있다.
- 후면에는 상황에 따른 대처 방법이 적혀있는 매뉴얼이 있다.

### 전면 메인 패널
- 모든 상태 표시를 전면 메인 패널에 모은다.
	- 설비별 고장 / 정상 표시등
	- 시스템 이상 타이머 (디지털 시계 형식, 1개)
	- 진행도 바, 내구도 게이지

| B | 우측면 | 슬라이더 4개. 목표를 보여주는 화면은 없다 |

## 3. 게임 상태
- 게임은 전체 진행도, 내구도(체력), 시스템 이상 타이머, 설비 A, B, C를 가진다.

| 상태 | 범위 | 시작 값 | 변화 |
| --- | --- | --- | --- |
| 진행도 | 0 ~ 100% | 0% | 모든 설비가 정상일 때만 일정 속도로 증가 |
| 내구도 | 0 ~ 최대값 | 최대값 | 시스템 이상 타이머가 끝날 때마다 감소. 회복 없음 (기본안) |
| 시스템 이상 타이머 | 0 ~ 제한 시간 | 정지 | 5. 타이머 규칙 참고 |
| 설비 | 정상 / 고장 | 모두 정상 | 고장 발생 시 고장, 수리 성공 시 정상 |

- 게임이 시작되면, 진행도가 차오르기 시작한다.
- 설비가 하나라도 고장 나면 진행도가 오르지 않는다.

## 4. 고장 규칙
- 고장은 시간 간격이 아니라, **진행도에 걸어 둔 고장 이벤트**로 발생한다.
- 진행도가 이벤트의 발생 지점에 도달하면, 그 이벤트에 정해진 설비들이 **동시에** 고장 난다.
- 발생 지점 : 이벤트마다 진행도 구간(예 : 20 ~ 30%)을 두고, 게임 시작 시 구간 안에서 무작위로 정한다. (기본안)
- 고장 대상 : 이벤트마다 설비를 지정하거나(정해둔 이벤트), 고장 수만 정하고 무작위로 고른다(정해둔 형태의 이벤트).
- 고장이 남아 있는 동안에는 진행도가 멈추므로 다음 이벤트가 오지 않는다. 동시 고장은 한 이벤트 안에서만 생긴다.
- 첫 고장 : 첫 이벤트까지 진행도가 차는 시간이 매뉴얼을 읽는 여유 시간이 된다.
- 난이도 : 진행도가 오를수록 동시에 고장 나는 설비 수를 늘린다.

### 고장 이벤트 표 (기본안)
| 순서 | 발생 구간 (진행도) | 고장 설비 | 의도 |
| --- | --- | --- | --- |
| 1 | 20 ~ 30% | A | 첫 고장. 목표가 보이는 A로 수리를 익힌다 |
| 2 | 40 ~ 50% | B | 소리로 찾는 B를 익힌다 |
| 3 | 60 ~ 70% | A, B 동시 | 첫 동시 고장 |
| 4 | 80 ~ 90% | A, B 동시 | 마지막 위기 |

- 고장 설비 칸에는 '무작위 1개'처럼 형태만 적어도 된다. 설비 C를 추가하면 이벤트에 C를 넣는다.

## 5. 타이머 규칙 : 시스템 이상 타이머
- 타이머는 설비 하나하나가 아니라, **시스템 전체가 정상이 아닌 시간**을 잰다.
- 설정 : 설비 일부가 고장 나서 전체 시스템이 정상 작동하지 않는 상태가 제한 시간 동안 이어지면, 시설이 손상되어 내구도가 깎인다.
- 표시 : 전면 메인 패널에 디지털 시계 형식으로 하나만 표시한다. 모든 설비가 정상일 때는 제한 시간 값에서 멈춰 있다. (기본안)

| 상황 | 타이머 동작 |
| --- | --- |
| 고장 이벤트 발생 (모두 정상 → 고장) | 제한 시간부터 카운트다운을 시작한다 |
| 일부 설비만 수리 | 영향 없음. 고장이 하나라도 남아 있으면 계속 흐른다 |
| 시간 초과 (0 도달) | 내구도가 감소하고, 고장이 남아 있으므로 제한 시간부터 다시 시작한다 (반복) |
| 모든 설비가 정상으로 복귀 | 멈추고 제한 시간으로 초기화한다 |

- 동시 고장은 한 순간에 함께 발생하므로, 모든 고장이 같은 제한 시간을 받는다.
- 타이머가 도는 동안에는 진행도가 멈춰 있어 고장이 추가되지 않는다. 따라서 추가 고장을 처리하는 규칙은 두지 않는다.

## 6. 수리 규칙
- 각 설비를 수리하기 위하여 플레이어는 규칙에 따라 조작 오브젝트를 조작한다.
- 완료 판정 : 목표 상태에 도달하면 자동으로 완료된다. 확인 조작은 없다.
- 잘못된 조작 : 페널티를 두지 않는다. 페널티는 제한 시간 내 수리 실패(내구도 감소)뿐이다.
- 수리 성공 시 : 시간 내에 설비를 수리하게 되면 공간 전면에 설비의 상태가 정상으로 표시되고, 진행도가 오르게 된다.
	- 해당 설비의 표시등이 초록으로 바뀌고 성공음이 난다.
	- 해당 설비의 장치를 초기화한다. 슬라이더는 기본값, 버튼은 전부 회색. (기본안)
	- 모든 설비가 정상이 되면 타이머가 멈추고 초기화되며, 진행도가 다시 오른다.
- 정상 설비의 장치 조작 : 장치는 반응(움직임, 색, 소리)하지만 설비와 게임에는 영향이 없다. (기본안)

## 7. 설비별 명세
- 목표는 고장 때마다 새로 무작위 생성한다. (기본안)
- 고장이 나도 장치는 현재 상태를 유지한다. 플레이어가 새 목표에 맞게 다시 조작한다. (기본안)
- 새 목표는 현재 장치 상태와 겹치지 않게 생성한다. (기본안)
> 자동 완료 방식이므로, 새 목표가 우연히 현재 상태와 같으면 고장 나자마자 수리된다. 이를 막는 규칙이다.

### 설비 A : 4x4 버튼 (좌측면)
- 4x4의 버튼의 On/Off 상태를 규칙에 따라 주어진 형태로 조작하여 수리한다.
- 조작 : 토글 버튼이다. 클릭하면 On / Off가 바뀐다.
- 목표 생성 : (작성) 예 : 16칸 중 무작위 N칸 On, 현재 형태와 최소 M칸 이상 다르게
- 목표 제시 : 좌측면 벽, A 버튼 바로 위의 화면에 목표 형태를 4x4로 보여준다. 고장일 때만 표시한다.
	- 화면을 보면서 바로 아래 버튼을 누를 수 있다. 매뉴얼 문구의 '화면'이 이 화면이다.
- 성공 판정 : 16개 버튼이 목표 형태와 모두 일치하면 자동 완료
- 조작 피드백 : (작성) 예 : 버튼 불빛, 클릭음
- 매뉴얼 문구 : A 요소가 고장 났을 시 4x4 버튼을 화면에 띄워진 형태로 누르시오.

### 설비 B : 슬라이더 4개 (우측면)
- 4개의 슬라이더를 조작한다. 소리로 슬라이더의 상태를 확인하고, 무작위로 주어지는 위치로 슬라이더를 이동하여야 한다.
- 조작 : 슬라이더 손잡이를 클릭한 채 드래그한다. 값은 연속값이다.
	- 슬라이더마다 무게감이 다르다. 무게감은 같은 양을 드래그해도 슬라이더가 움직이는 정도이다. (무거울수록 적게 움직인다)
	- 슬라이더를 잡고 있는 동안 이동은 멈추고, 시점은 매우 낮은 감도로 움직인다. (기본안)
	- 구현 방법은 「구현 메모」의 슬라이더 드래그 참고
- 목표 생성 : 슬라이더마다 무작위 위치. 현재 위치에서 허용 범위 밖에 생성한다. (기본안)
- 목표 제시 : 목표 위치는 어디에도 보여주지 않고, 소리로만 찾는다. 소리로 찾는 방법은 후면 매뉴얼에 적는다.
- 성공 판정 : 4개 슬라이더가 모두 목표 범위 안에 들어가면 자동 완료. 허용 범위는 슬라이더당 10% (10. 수치)
- 조작 피드백
	- 잡고 움직이는 동안 : '스스스', '드르륵' 같은 기본 슬라이더 소리
	- 목표 범위에 들어가는 순간 : '철컥', '띠링' 같은 강한 소리
	- 4개 모두 목표 범위에 들어가면 : 시각 + 청각 피드백을 동시에 주며 B 설비가 수리되었음을 알린다. (= 수리 성공 피드백)
	- 범위 안에 들어간 슬라이더는 시각적으로 따로 표시하지 않는다. 어느 슬라이더를 맞췄는지는 플레이어가 기억한다.
- 매뉴얼 문구 : 4개의 슬라이더를 각 올바른 위치에 위치시키시오. 소리에 집중해야 함! (「공간 후면의 매뉴얼 작성」 초안)

### 설비 C : [미정]
- A, B를 먼저 완성하고 시간이 남으면 추가한다. 추가하게 되면 위와 같은 항목을 채운다.

> 게임 상태에 따른 이벤트와 연출 목록이다. 장치별 조작 피드백은 7. 설비별 명세에 있다.

| 이벤트 | 시각 | 사운드 |
| --- | --- | --- |
| 평상시 (모두 정상) | 전면 패널 초록 불 | 웅웅거리는 기계 소리 |
| 고장 발생 | 고장 난 설비 표시등 붉은 불, 타이머 시작 | 사이렌, 고장 난 듯한 기계 소리 |
| 동시 고장 | 고장 수만큼 붉은 표시 면적 증가 | 고장 수만큼 사이렌 음량 증가 |

| 패배 | 패배 UI | (작성) |

## 9. 게임 흐름
- 시작 : 씬을 불러오면 바로 시작한다. 첫 고장 이벤트까지의 시간(약 20 ~ 30초)이 준비 시간 역할을 한다. (기본안)
- 승리 : 진행도가 100%가 되면 승리 UI를 표시한다.
- 패배 : 내구도가 0이 되면 패배 UI를 표시한다.
- 종료 : 고장 발생과 타이머를 멈추고, 승리 / 패배 UI에 재시작 버튼을 둔다. (기본안)
- 승리와 패배는 동시에 일어나지 않는다. 진행도는 모든 설비가 정상일 때만 오르고, 내구도는 고장이 있을 때만 깎이기 때문이다.

## 10. 수치
> 한 판 목표 : 깔끔하게 플레이하면 약 3분, 헤매거나 실패하면 5분 안팎.
> 3분 ≈ 진행도를 채우는 100초 + 고장 이벤트 4번의 수리 약 90초 (A 10초, B 20초, A·B 동시 30초 × 2)
> 아래 초기값은 이 기준으로 잡은 제안값이다. (기본안)

| 항목 | 초기값 | 비고 |
| --- | --- | --- |
| 진행도 증가 속도 | 1 %/초 | 고장 없이 100초에 가득 찬다 |
| 고장 이벤트 | 4. 고장 이벤트 표 | 첫 이벤트(20 ~ 30%)까지의 20 ~ 30초가 매뉴얼을 읽는 여유 시간 |
| 제한 시간 | 40 초 | 시스템 이상 타이머의 길이. A·B 동시 고장을 깔끔하게 고치면 조금 남는 정도 |
| 내구도 최대값 | 3 | |
| 시간 초과 시 내구도 감소량 | 1 | 3번 시간 초과하면 패배 |
| 내구도 낮음 기준 | 1 | 앰비언스를 추가하는 시점. 한 번 더 초과하면 패배 |
| 이동 속도 | 3 m/초 | |
| 상호작용 거리 | 2 m | 「구현 메모」 예시값 |
